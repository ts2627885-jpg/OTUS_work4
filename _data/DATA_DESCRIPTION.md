# Описание данных

## Обзор

Датасет содержит исторические данные о деятельности 5 автозаправочных станций (АЗС) западного региона за период с июня 2025 по июль 2026. Данные включают информацию о продажах топлива, ценах, метеорологических условиях, транспортном потоке и конкурентной среде.

**Общая информация:**
- **Период:** 01.06.2025 – 07.07.2026 (15+ месяцев)
- **Объект изучения:** 5 АЗС (АЗС 123, 124, 125, 126, 127)
- **Общий размер:** 11.95 МБ
- **Количество файлов:** 7 CSV-файлов

## Предварительная обработка данных

### Проблемы, которые могут возникнуть
1. **Пропущенные значения** — в файле цен конкурентов много NULL/пустых полей
2. **Форматы данных** — разные форматы дат (YYYY-MM-DD vs DD.MM.YYYY_HH:MM:SS)
3. **Разные гранулярности** — почасовые данные в toplivo.csv, ежедневные в других файлах
4. **Матричный формат** — сопутствующие товары требуют преобразования

### Рекомендуемые преобразования
- Стандартизировать форматы дат
- Заполнить пропущенные значения (прямой перенос, интерполяция)
- Преобразовать матричный формат в долгий
- Aggregate почасовые данные в ежедневные при необходимости
- Нормализовать значения цен (учитывая инфляцию)
