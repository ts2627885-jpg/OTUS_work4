# База азс: загрузка из CSV в PostgreSQL

Пайплайн очищает исходные CSV и пересобирает схему `azs` в PostgreSQL. Запуск полностью пересоздаёт схему, поэтому старые данные в ней заменяются.

## Состав

| Файл | Назначение |
|---|---|
| `run_pipeline.sh` | Точка входа: очистка, схема, загрузка, правила, контроль |
| `load_competitor_prices.py` | Очистка `competitor_prices.csv` |
| `load_all.py` | Очистка `prices.csv`, `traffic_data.csv`, `weather_data.csv`, `shop_sales.csv` |
| `clean_promotions.py` | Очистка `promotions.csv` |
| `schema.sql` | Схема `azs`: таблицы, ключи, ограничения |
| `gen_load.py` | Генерация `load.sql` с временными таблицами `stg` |
| `transform.sql` | Перенос из `stg` в таблицы `azs` |
| `post.sql` | Заполнение цен и исключение первого дня трафика |

## Требования

- PostgreSQL 13+ (проверено на 16) и `psql`
- Python 3 с `pandas`
- Linux, macOS или WSL

## Запуск

```bash
export PGHOST=localhost PGUSER=postgres PGPASSWORD='пароль' PGDATABASE=azs
./run_pipeline.sh /путь/к/папке_с_csv [папка_результатов]
```

Папка с CSV должна содержать `competitor_prices.csv`, `prices.csv`, `promotions.csv`, `shop_sales.csv`, `stations.csv`, `traffic_data.csv`, `weather_data.csv`.

Перед запуском сделайте резервную копию, если база уже заполнена:

```bash
pg_dump -n azs -d azs > backup.sql
```

## Правила обработки

**Идентификатор АЗС.** Последние три цифры названия или идентификатора: 172, 173, 603, 604, 606. Совпадает во всех файлах.

**Конкуренты.** Привязаны к АЗС (`competitor.station_code`). Количество совпадает с `stations.csv`. Слот из описания не используется: один слот может содержать разных конкурентов в разное время.

**Цены конкурентов.** Значение 0 означает «не предлагалось»: `is_offered = FALSE`, `price = NULL`. Все строки сохраняются, включая одновременные записи с разными ценами: первичный ключ — номер строки в файле.

**Даты в ценах.** Вид `27.апр` — опечатка, значит 27.04.

**Собственные продажи.** `sales_volume = 0` означает «не продавалось». Если продажи есть, а цена 0, цена заполняется предыдущим известным значением по той же АЗС и топливу (`price_fill_method = 'prev'`). Если предыдущего нет, берётся следующее (`'next'`). Остаются 14 строк без цены: АИ-100 био на АЗС 173, сентябрь 2026.

**Трафик.** Первый день АЗС 172 (2026-02-12) исключён как неполный. Пропуски и нули оставлены. Колонки `traffic_Truck`, `traffic_Truck_long` и `traffic_Truck_short` относятся к разным классификаторам и не сверяются.

**Акции.** ВИНК не загружается. Строка без дат (№25) исключена. Дата 2026-12-31 считается реальным сроком.

## Открытые вопросы

1. Перевыгрузка цен АИ-100 био для АЗС 173 за сентябрь 2026: сейчас 14 строк без цены.
2. Падение числа записей цен конкурентов с июля 2026 в 2–3 раза. Формат не менялся, частота изменений у наших цен и у конкурентов снизилась тоже. Оставлено как есть по решению заказчика.
3. Расшифровка `SUG`, `KPG`, `SPG` как СУГ, КПГ, СПГ подтверждена.
