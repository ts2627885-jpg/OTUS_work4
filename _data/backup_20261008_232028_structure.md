# Структура папки `backup_20261008_232028`

Папка содержит резервную копию 7 CSV-файлов с исходными данными АЗС-Пульта за период 01.06.2025 – 21.09.2026. Файлы в кодировке UTF-8, разделитель — `;` или `,` (см. таблицу).

Расположение: `azs-pult-fullstack/_data/backup_20261008_232028/`

## Состав

```
backup_20261008_232028/
├── competitor_prices.csv   # цены конкурентов              (~12,4 МБ, 59 942 строки)
├── prices.csv              # продажи и цены по АЗС, по дням (~0,7 МБ,  2 390 строк)
├── promotions.csv          # акции ВИНК                     (~20 КБ,    128 строк)
├── shop_sales.csv          # продажи сопутствующих товаров  (~137 КБ,    35 строк)
├── stations.csv            # справочник АЗС                 (~2 КБ,       5 строк)
├── traffic_data.csv        # загрузка АЗС по дням           (~89 КБ,  1 021 строка)
└── weather_data.csv        # погода по АЗС и дням           (~143 КБ, 2 390 строк)
```

## Описание файлов

| Файл | Содержимое | Ключевые колонки |
|------|-----------|------------------|
| `stations.csv` | Справочник 5 АЗС: тип дороги, число колонок по видам топлива, наличие магазина, автомойки, кафе, гостиницы, список конкурентов рядом | `АЗС`, `station_id`, `station_name`, `road_type`, `total_pumps`, `has_shop`, `competitors_*` |
| `prices.csv` | Ежедневные данные по каждой АЗС: объёмы продаж по видам топлива, цены, календарные признаки, конкуренты, доля корпоративных клиентов | `Идентификатор АЗС`, `Временная метка`, `sales_AI92…sales_SPG`, `price_AI92…price_SPG`, `total_fuel_sales`, `is_holiday`, `competitor_price_AI92`, `customer_loyalty_score` |
| `competitor_prices.csv` | Длинный формат: цены конкурентов по видам топлива и по времени | `Переменная`, `Идентификатор АЗС`, `Временная метка`, `Значение`, `Brand`, `Number` |
| `promotions.csv` | Акции ВИНК: название, период, категория, охват, описание механики | `ВИНК`, `Акция`, `Дата начала`, `Дата конца`, `Категория`, `Охват (нормализованный)` |
| `shop_sales.csv` | Широкий формат: продажи товаров магазинов (напитки и т.д.) по датам в колонках | `Переменная`, `Тип`, `АЗС`, далее колонки-даты `ДД.ММ.ГГГГ` |
| `traffic_data.csv` | Ежедневная загрузка АЗС: число легковых, грузовых, интенсивность, плотность, уровень обслуживания | `Дата`, `Название АЗС`, `traffic_*` |
| `weather_data.csv` | Ежедневная погода по каждой АЗС | `station_name`, `date`, `temperature_C`, `humidity_%`, `pressure_hPa`, `wind_speed_ms`, `precipitation_mm`, `weather_type` |

## Связи между файлами

- Станции связываются через `Идентификатор АЗС` (`prices.csv`, `competitor_prices.csv`) и `station_name` / `Название АЗС` (`weather_data.csv`, `traffic_data.csv`, `shop_sales.csv`). Значения вида `АЗС 172` и `Запад-МФ-6910172` — это одна и та же станция в разных записях.
- Даты записаны в разных форматах: `YYYY-MM-DD` (`prices.csv`, `weather_data.csv`, `traffic_data.csv`), `DD.MM.YYYY_HH:MM:SS` (`competitor_prices.csv`), `DD.MM.YYYY` (колонки `shop_sales.csv`).

## Покрытие

- 5 АЗС в подпапке `_/`: 121, 122, 123, 124, 125 (это актуальные данные, которые загружаются в БД).
- `promotions.csv` содержит 54 записи акций (строк в файле больше, так как описания многострочные).
- Значения продаж в `prices.csv` и `shop_sales.csv` синтетические; нули там, где топлива или товара нет, сохранены.
- `prices.csv` и `weather_data.csv` содержат по 2 390 строк = 5 станций × 478 дней.

## Примечания

- Папка `_excel/` содержит копии файлов с переименованными станциями (АЗС 121–125 вместо кодов в данных конкурентов и акций) и BOM в начале файлов, чтобы Excel правильно показывал кириллицу. Исходные файлы в `_/` не менялись этим переименованием.
