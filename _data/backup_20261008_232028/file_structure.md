# Описание структуры файлов

Все файлы в кодировке UTF-8. Разделитель полей в CSV — точка с запятой (`;`). В первом заголовке у некоторых файлов присутствует BOM-символ.

---

## 1. `competitor_prices.csv`

**Назначение:** цены конкурентов на топливо по АЗС.
**Объём:** 59 942 строки.

| Колонка | Описание |
|---|---|
| Наименование групп данных | Группа данных |
| Переменная | Название показателя (например, цена конкретного вида топлива) |
| Описание | Пояснение к показателю |
| Идентификатор АЗС | ID заправочной станции |
| Название АЗС | Название станции |
| Временная метка | Дата и время замера |
| Значение | Значение показателя (цена) |
| Brand | Бренд АЗС |
| Number: String | Служебная колонка |

---

## 2. `prices.csv`

**Назначение:** собственные продажи, цены и факторы по АЗС с разбивкой по времени.
**Объём:** 2 390 строк.

**Группы колонок:**

- **Идентификация:** `№ п/п`, `Идентификатор АЗС`, `Название АЗС`, `Временная метка`
- **Объёмы продаж по видам топлива:** `sales_AI92`, `sales_AI92_bio`, `sales_AI95`, `sales_AI95_bio`, `sales_AI100_bio`, `sales_DT`, `sales_DT_bio`, `sales_SUG`, `sales_KPG`, `sales_SPG`, `total_fuel_sales`
- **Цены по видам топлива:** `price_AI92`, `price_AI92_bio`, `price_AI95`, `price_AI95_bio`, `price_AI100_bio`, `price_DT`, `price_DT_bio`, `price_SUG`, `price_KPG`, `price_SPG`
- **Календарные признаки:** `hour`, `day_of_week`, `week_of_year`, `month`, `quarter`, `day`, `year`, `season`, `is_weekend`, `is_holiday`, `holiday_name`
- **Конкуренты:** `competitors_wink`, `competitors_private`, `competitors_конкурент1` … `competitors_конкурент4`, `competitor_price_AI92`
- **Прочее:** `corporate_customer_ratio` (доля корпоративных клиентов), `customer_loyalty_score` (индекс лояльности клиентов)

Виды топлива: AI92, AI95, AI100 (суффикс `_bio` — биотопливные варианты), DT (дизель), SUG (сжиженный газ), KPG и SPG (сжатый и сжиженный природный газ).

## 4. `shop_sales.csv`

**Назначение:** выручка / продажи магазинов на АЗС по дням.
**Объём:** 35 строк.
**Формат:** широкий — каждая дата отдельной колонкой.

| Колонка | Описание |
|---|---|
| № п/п | Порядковый номер |
| Наименование групп | Группа показателей |
| № п/п в группе | Порядковый номер внутри группы |
| Переменная | Название показателя |
| Тип | Тип показателя |
| Описание | Пояснение |
| АЗС | Название станции |
| 01.06.2025 … 21.09.2026 | Значения показателя по каждому дню (от 01.06.2025 до 21.09.2026, ежедневно) |

## 5. `stations.csv`

**Назначение:** справочник характеристик АЗС.
**Объём:** 5 строк, 36 колонок.

**Группы колонок:**

- **Идентификация:** `АЗС`, `station_id`, `station`, `station_name`
- **Дорога и местоположение:** `road_type` (тип дороги), `road_level` (категория дороги), `direction` (направление), `settlement_size` (размер населённого пункта), `distance_to_city_km` (расстояние до города, км)
- **Количество колонок (ТРК) по видам топлива:** `num_pumps_AI92`, `num_pumps_AI92_bio`, `num_pumps_AI95`, `num_pumps_AI95_bio`, `num_pumps_AI100_bio`, `num_pumps_DT`, `num_pumps_DT_bio`, `num_pumps_SUG`, `num_pumps_KPG`, `num_pumps_SPG`, `total_pumps` (всего)
- **Магазин и сервисы:** `has_shop`, `shop_area_m2` (площадь магазина, м²), `has_car_wash` (мойка), `has_tire_service` (шиномонтаж), `has_cafe` (кафе), `has_hotel` (гостиница), `has_shop_молельная_комната` (молельная комната), `has_shop_прачечная` (прачечная), `has_shop_электрозарядная_станция` (электрозарядная станция), `has_shop_подкачка_шин` (подкачка шин)
- **Конкуренты:** `competitors_wink`, `competitors_конкурент1` … `competitors_конкурент4`, `competitors_private`

Признаки `has_*` и `competitors_wink`, `competitors_private` — бинарные (0/1).

## Связи между файлами

- Общий ключ АЗС: `Идентификатор АЗС` / `station_id` / `АЗС` / `Название АЗС` (названия и ID в разных файлах могут быть записаны по-разному и требуют приведения к единому виду).
- Временной ключ: `Временная метка` (prices, competitor_prices), `Дата` (traffic), `date` (weather), даты-колонки (shop_sales).
- `prices.csv` и `weather_data.csv` содержат одинаковое число строк (2 390) — возможно, одинаковая детализация по времени и станциям.
