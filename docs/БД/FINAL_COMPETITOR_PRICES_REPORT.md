## 📊 Исходное состояние vs Финальное решение

### Проблема

| Аспект | Было | Должно быть |
|--------|------|-----------|
| **Загружено записей** | 10,926 (18.2%) | 27,345 (100%) ✅ |
| **Охват данных** | 40% от валидных | 100% от валидных ✅ |
| **Временная точность** | Только дата | Дата + время ✅ |
| **Обновления в день** | Одно значение | До 58 значений ✅ |
| **Проблема** | ON CONFLICT отклонял дубликаты | ON CONFLICT обновляет цену ✅ |

### Причина потери 16,419 записей

В исходном скрипте `fix_competitor_prices_v2.py`:
- Использовалась только дата (`split('_')[0]`) 
- Отклонялось время суток
- Одна дата = одна запись (дубликаты отклонялись)
- Результат: 27,345 валидных цен → только 10,926 загружено (40% успеха)

### Решение

**`fix_competitor_prices_with_time.py`** (новый скрипт):
- ✅ Использует полную временную метку `DD.MM.YYYY_HH:MM:SS`
- ✅ Преобразует в `YYYY-MM-DD HH:MM:SS` для PostgreSQL
- ✅ Каждое обновление цены = отдельная запись
- ✅ Стратегия `ON CONFLICT ... DO UPDATE` обновляет если цена изменилась
- ✅ Результат: **27,345 → 27,345 (100% успеха)** ✅

## 📊 Практические применения

### 1. Мониторинг цен конкурентов

```sql
-- Последние цены каждого конкурента
SELECT 
    c.brand_name,
    ft.code,
    ROUND(cph.price_rub, 2) as price,
    cph.created_at
FROM competitor_price_history cph
JOIN competitor c ON cph.competitor_id = c.id
JOIN fuel_type ft ON cph.fuel_type_id = ft.id
WHERE cph.created_at = (
    SELECT MAX(created_at) FROM competitor_price_history
)
ORDER BY c.brand_name, ft.code;
```

### 2. Анализ ценовых тренов

```sql
-- Как менялась цена AI95 за последние 7 дней
SELECT 
    DATE(created_at) as date,
    c.brand_name,
    ROUND(AVG(price_rub), 2) as avg_price,
    ROUND(MIN(price_rub), 2) as min_price,
    ROUND(MAX(price_rub), 2) as max_price
FROM competitor_price_history cph
JOIN competitor c ON cph.competitor_id = c.id
JOIN fuel_type ft ON cph.fuel_type_id = ft.id
WHERE ft.code = 'AI95' 
  AND cph.created_at >= CURRENT_DATE - 7
GROUP BY DATE(created_at), c.brand_name
ORDER BY date DESC, c.brand_name;
```

### 3. Корреляция с продажами

```sql
-- Когда конкурент поднял цены на AI95?
SELECT 
    DATE(created_at) as date,
    c.brand_name,
    ROUND(MAX(price_rub), 2) as max_price,
    ROUND(MIN(price_rub), 2) as min_price,
    ROUND(MAX(price_rub) - MIN(price_rub), 2) as price_change
FROM competitor_price_history cph
JOIN competitor c ON cph.competitor_id = c.id
JOIN fuel_type ft ON cph.fuel_type_id = ft.id
WHERE ft.code = 'AI95'
GROUP BY DATE(created_at), c.brand_name
HAVING MAX(price_rub) - MIN(price_rub) > 0.5  -- Скачок цены
ORDER BY date DESC;
```
