## ✅ После завершения

```bash
# Проверить записи
sudo -u postgres psql azs_pult -c "
  SELECT COUNT(*) as records FROM competitor_price_history;
"
# Должно вывести: 27345

# Посмотреть последние цены
sudo -u postgres psql azs_pult -c "
  SELECT c.brand_name, ft.code, cph.price_rub, cph.created_at
  FROM competitor_price_history cph
  JOIN competitor c ON cph.competitor_id = c.id
  JOIN fuel_type ft ON cph.fuel_type_id = ft.id
  WHERE cph.created_at = (SELECT MAX(created_at) FROM competitor_price_history)
  LIMIT 10;
"
```

## 🆘 Если что-то не работает

1. **PostgreSQL не запускается** → `sudo systemctl start postgresql`
2. **Таблица не существует** → Прочитать `COMPETITOR_PRICES_REQUIREMENTS.md` раздел "Требования к схеме БД"
3. **Скрипт не находит CSV** → Проверить переменную `DATA_DIR` в скрипте
4. **Ошибка при загрузке** → Смотреть `README_INSTALLATION.md` раздел "Решение проблем"
