## 1. Рекомендации и расчёты

- **PRICE-004 сведён в одну рекомендацию** `PRICE-004-SUMMARY`: «Эластичность не оценена для N из M пар». В причине перечислены пары и их причины. Тест предлагается только парам с вариацией цены. Было 12 одинаковых карточек, стало одна. Пересчёт: 24 активных рекомендации (было 33).
- **PRICE-001 без оценки эластичности**: вместо «Установить цену X» пишется «Ориентир X ₽/л (эффект не оценён)».
- **Модели эластичности отдают причину и выборку**: `reason`, `se`, `n` в `rules.service.ts`.
- В `docs/CALCULATIONS.md` описание PRICE-004 обновлено, добавлены интервалы и пометка трафика.

## 2. Вкладка «Ценовая политика»

- Колонка «Почему нет оценки» вместо «—». Для биотоплив (AI100_bio, DT_bio) причина: вид топлива не входит в расчёт.
- В примечании сводка: значимая оценка (по станции или по сети) у 5 из 21 пар, со списком пар.
- Подписи: «Изменение объёма при +1 ₽, %», «Интервал 95%, %», «Наблюдений».
- Интервал 95%: эластичность ± 1.96·se. Для AI-92 станции 172 это −8.1 … −0.5% при +1 ₽. В симуляторе: «(95%: от … до …%)».

## 3. Вкладка «Трафик»

## 5. Загрузка CSV

- Можно выбрать и загрузить несколько файлов сразу (до 20).
- Бэкенд: `POST /api/import/csv`, поле `file`, файлы по очереди. Ошибка одного файла не останавливает остальные.
- Пересчёт рекомендаций один раз после всего пакета (`importCsv(..., { recalc: false })`).
- Страница импорта: список выбранных файлов, таблица результатов по каждому, строка про пересчёт.
- Проверено через API: два файла в одном запросе, ошибка типа в одном файле не мешает второму.
