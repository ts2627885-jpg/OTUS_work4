## 📋 Типы ошибок по категориям

### Валидация (Validation)
```
400 Bad Request
• Неверный формат (email, дата, число)
• Пустые обязательные поля
• Значение вне диапазона
• Неверный тип данных

UX: Поле выделено красным + объяснение + примеры
Retry: НЕТ
Severity: 🟡 High
```

### Аутентификация/Авторизация (Auth)
```
401 Unauthorized / 403 Forbidden
• Неверные учетные данные
• Токен истек
• Недостаточно прав
• Попытка доступа к чужим данным

UX: Кнопки действий (login, refresh, запрос доступа)
Retry: ДА (для refresh, не для пароля)
Severity: 🟡 High / 🔴 Critical
```

### Данные (Data)
```
404 Not Found / 409 Conflict
• Ресурс не найден
• Дублирование
• Версионирование конфликтов

UX: Опции разрешения конфликтов
Retry: НЕ ВСЕГДА
Severity: 🟡 High
```

### Сеть (Network)
```
0 / 504 Gateway Timeout / 503 Service Unavailable
• Интернет отключен
• Timeout
• Server down
• Rate limiting (429)

UX: Offline banner / Retry with backoff
Retry: ДА
Severity: 🟡 High / 🔴 Critical
```

### Сервер (Server)
```
500 Internal Server Error
• Ошибка базы данных
• Ошибка алгоритма
• Неожиданное исключение

UX: "Ошибка сервера. Мы работаем" + retry
Retry: ДА (3x exponential backoff)
Severity: 🔴 Critical
```

### Бизнес-логика (Business)
```
400 Bad Request + custom error code
• Цена ниже себестоимости
• Нарушение ограничений
• Конфликт правил

UX: Объяснение ограничения + опции
Retry: НЕТ
Severity: 🟡 High
```

## 🔧 Стратегии обработки по типам

### Exponential Backoff для Retry
```
Attempt 1: 1 sec
Attempt 2: 2 sec
Attempt 3: 4 sec
Max: 30 sec

Formula: delay = min(initialDelay * (2 ^ attempt), maxDelay)
```

### Polling для долгих операций
```
CSV импорт:
Poll каждые 500 мс
Timeout: 5 минут
Fallback: показать "Импорт в фоне"
```

### Cache для offline
```
Dashboard:
Cache lifetime: 1 час
При offline: показать кэшированные данные
При online: синхронизировать

Очередь операций:
Сохранить в localStorage
Синхронизировать при восстановлении связи
```

## 🎯 Checklist для каждого endpoint

Когда добавляете новый API endpoint, убедитесь:

- [ ] **Валидация входных данных** (400)
- [ ] **Проверка прав доступа** (401, 403)
- [ ] **Обработка отсутствия ресурса** (404)
- [ ] **Разрешение конфликтов** (409)
- [ ] **Логирование ошибок** (audit trail)
- [ ] **Graceful degradation** (показать что-то полезное)
- [ ] **Timeout защита** (504)
- [ ] **Rate limiting** (429)
- [ ] **Осмысленные коды ошибок** (не просто 500)
- [ ] **Документация для фронтенда** (какие коды ошибок, как их обрабатывать)

## 📱 Frontend Error Handler Template

```typescript
// API Client с полной обработкой ошибок
class ApiClient {
  async request<T>(url: string, options: RequestOptions): Promise<T> {
    try {
      // 1. Проверка интернета
      if (!navigator.onLine) {
        return this.handleOffline(url, options);
      }
      
      // 2. Выполнение запроса с таймаутом
      const response = await Promise.race([
        fetch(url, options),
        this.timeout(30000) // 30 сек timeout
      ]);
      
      // 3. Обработка HTTP ошибок
      if (!response.ok) {
        return this.handleHttpError(response);
      }
      
      // 4. Парсинг JSON
      const data = await response.json();
      return data;
      
    } catch (error) {
      // 5. Обработка сетевых ошибок
      return this.handleNetworkError(error);
    }
  }
  
  private handleHttpError(response: Response) {
    const status = response.status;
    
    switch (status) {
      case 400:
        return this.handle400BadRequest(response);
      case 401:
        return this.handle401Unauthorized(response);
      case 403:
        return this.handle403Forbidden(response);
      case 404:
        return this.handle404NotFound(response);
      case 409:
        return this.handle409Conflict(response);
      case 429:
        return this.handle429TooManyRequests(response);
      case 500:
        return this.handle500ServerError(response);
      case 503:
        return this.handle503Unavailable(response);
      case 504:
        return this.handle504Timeout(response);
      default:
        return this.handleUnknownError(response);
    }
  }
}
```
